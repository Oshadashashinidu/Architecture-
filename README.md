# GloveXcel Architecture Visualizer

This directory is a portable static page. Copy the entire `glovexcel-architecture` folder into another repository and open or deploy `index.html`.

## Contents

- `index.html` — page markup, styling, SVG icons, animations, and interaction logic.

No package installation, build command, external image, font, framework, or JavaScript dependency is required.

## Run locally

You can open `index.html` directly in a browser. To serve it over HTTP instead, run any static file server from this directory, for example:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy

The folder can be used as a static-site root on GitHub Pages, Vercel, Netlify, Cloudflare Pages, or any conventional web server.
